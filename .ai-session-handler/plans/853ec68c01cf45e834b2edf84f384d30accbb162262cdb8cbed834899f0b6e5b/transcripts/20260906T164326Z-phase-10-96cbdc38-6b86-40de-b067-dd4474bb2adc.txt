[codex] ## Human-Reviewed Image Tracing
[codex] 
[codex] A rebuilt sandbox image provides [VGG Image Annotator (VIA) 3.0.13](https://www.robots.ox.ac.uk/~vgg/software/via/), an open-source BSD-2-Clause standalone application with ordered polygon, line, and polyline annotations. The build downloads VGG's [official versioned archive](https://www.robots.ox.ac.uk/~vgg/software/via/downloads/via3/via-3.0.13.zip), verifies archive SHA-256 `d16fac5ac83507587845c04644bdbe81896865f2cb963d570bf0f52d48e7d793`, verifies the standalone image annotator SHA-256 `44de1edcee45a0c442dcd028316cdce1647b4fb1a3ca3669b07cd77f39e5fc98`, and preserves the upstream license under `/opt/via-annotator`.
[codex] 
[codex] VIA is a human-operated annotation tool. The human selects and orders every polygon vertex and every two-point line or polyline. ImageMagick may produce deterministic metadata, crops, and review overlays, but automatic edge detection or other automated tracing must never produce authoritative geometry.
[codex] 
[codex] After changing the sandbox image, use **Dev Containers: Rebuild and Reopen in Container** from the VS Code Command Palette. Do not use a normal window reload: the Node.js, VIA, ImageMagick, and browser prerequisites are image contents and are available only after the rebuild completes.
[codex] 
[codex] Verify the rebuilt environment:
[codex] 
[codex] ```bash
[codex] node --version
[codex] via-annotator --version
[codex] via-annotator --check
[codex] identify -version
[codex] convert -version
[codex] playwright --version
[codex] playwright install --list
[codex] ```
[codex] 
[codex] `node --version` must report major version 24, `via-annotator --check` must report a valid 3.0.13 installation without starting a server, and Playwright's list must include Chromium under `/opt/playwright-browsers`.
[codex] 
[codex] Start VIA in a terminal:
[codex] 
[codex] ```bash
[codex] via-annotator
[codex] # Or choose another local port:
[codex] via-annotator --port 8766
[codex] ```
[codex] 
[codex] The default local URL is `http://localhost:8765/via_image_annotator.html`. The launcher remains in the foreground; press `Ctrl+C` in that terminal to stop it cleanly. VIA never starts as a service or background process.
[codex] 
[codex] For private source images, choose **Add Local Files** in VIA and select the original image with the browser file picker. Create the ordered polygon and the required two-point line or polyline annotations manually, then save the VIA project and export its JSON for the reviewed import workflow. The launcher binds strictly to `127.0.0.1` and serves only immutable files in `/opt/via-annotator`; it neither serves `/workspace` nor provides a file-upload endpoint. Selected local files are read in the browser and are not sent to the static server. Do not use remote-file or project-sharing features for private images.

[codex] ## Ownership and policy
[codex] 
[codex] Renovate is the only service allowed to open dependency update pull requests.
[codex] Dependabot remains alert-only: keep the dependency graph and Dependabot alerts
[codex] enabled, disable Dependabot version updates and overlapping Dependabot security
[codex] update pull requests, and let Renovate consume alerts when its App permission
[codex] allows that. Never enable automerge, including for security fixes.
[codex] 
[codex] The shared policy is
[codex] [`renovate-presets/default.json`](../renovate-presets/default.json). Repository
[codex] configuration extends it and adds only repository-specific manager paths and
[codex] extraction rules. Routine pull requests are created weekly, with no more than
[codex] three open routine pull requests and two new routine pull requests per hour in
[codex] one repository. Vulnerability fixes use Renovate's dedicated alert path and an
[codex] unrestricted schedule. Major, chart, stateful, platform, and checksum-coupled
[codex] updates require Dependency Dashboard approval.
[codex] 
[codex] Patch, minor, and major proposals remain distinct. Digest refreshes must retain
[codex] an immutable digest and any image flavor suffix. Reviewers must independently
[codex] verify Linux ARM64 support. An available tag or a changed digest is not evidence
[codex] of architecture support, embedded package versions, vulnerability remediation,
[codex] or upstream support status.
[codex] 
[codex] The following stay outside Renovate ownership:
[codex] 
[codex] - historical/generated outputs and the retained stale test suites
[codex] - local `:latest` and generated `:tilt-*` images listed by the image-pinning
[codex]   inventories
[codex] - first-party production images and their synchronized manifest, inventory,
[codex]   overlay, runtime metadata, and API-docs metadata
[codex] - Pod Security compatibility labels
[codex] - arbitrary per-platform checksum calculation
[codex] 
[codex] Renovate may propose checksum-coupled tool versions, but dashboard approval and
[codex] the existing checksum verification remain mandatory. A reviewer must update the
[codex] complete checksum table; no validation may be weakened to merge the proposal.
[codex]
