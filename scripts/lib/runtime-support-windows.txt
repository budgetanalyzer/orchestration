# access and prints every line whose support end date has passed or falls within
# 90 days. A person keeps the dates current: re-check each source during the
# quarterly review and whenever a selected line changes.

#   runtime       product name

#   selected_in   where the line is selected (repository: path)

#   note          how support_end was derived, when not a published day
#
